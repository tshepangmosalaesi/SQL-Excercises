# SQL-Excercises
### **BrightLearn SQL Foundations & Advanced Exercises**
A comprehensive repository containing practical, multi-format SQL exercises designed to build database query proficiency. The coursework spans foundational syntax, set operations, complex joins, and advanced conditional logic using real-world business scenarios.

### **Tech Stack & Tools**
 **Platforms:** Databricks SQL
** MySQLVersion Control:** GitHub
** Analog Development:** Pen, Paper, Ruler, PDF Scanner

###  **Repository Structure**
 The exercises in this repository transition from strict pen-and-paper logic checks to multi-platform digital execution.

### ** Module 1: SQL Foundations (Pen & Paper)**
**Exercise 01: SELECT & Filtering**
- Focus: Data retrieval (SELECT *, DISTINCT), sorting (ORDER BY), constraints (LIMIT), and logical filtering (WHERE, AND, OR, NOT, IN).
- Deliverables: Handwritten queries (SQL keywords in UPPERCASE, names in lowercase) and hand-drawn predicted output tables to verify logic execution before running code.

### **Exercise 02: Aggregate Functions & Operators**
- Focus: Structural aggregations (COUNT, SUM, AVG, MIN, MAX), grouping structures (GROUP BY, HAVING), and range operations (BETWEEN).
- Deliverables: 15 comprehensive hand-drawn query blueprints mapping metrics across 5 structural tables.

### **Module 2: Data Transformation & Architecture (Databricks / Multi-Platform)**
**Exercise 03: Date Functions**
- Focus: Temporal analysis (DAYNAME, MONTH, YEAR, DATEDIFF, DATEADD, DATE_TRUNC, LAST_DAY).
- Environment: Adapted explicitly for Databricks SQL / MySQL syntax standards while maintaining multi-engine awareness for Snowflake and BigQuery.

**Exercise 04: Relational Joins**
- Focus: Multi-table data assembly (INNER JOIN, LEFT JOIN, FULL OUTER JOIN) across a 5-table retail streaming service dataset. - Dataset Context: Financial audit logs and master records for a fictional African retail bank (NexBank).

### **Module 3: Advanced SQL Logic**
**Exercise 2.1: Advanced NULL Functions**
- Focus: Conditional missing value logic (IFNULL(), ISNULL(), COALESCE()).
- Submission Workflow: Queries and tables are structurally mapped out by hand, compiled via a clean page scanner, and committed to this repository as an engineered PDF artifact.
